================================================================================
ОПИСАНИЕ РАСЧЁТА МЕТРИК HR-ОТЧЁТА
================================================================================
Документ описывает, как рассчитываются все показатели в отчёте.
Источники данных: Excel-файл с листами «Список сотрудников», «Увольнение»,
«Увольнения Склад и Торги» (последний — по индексу, если имя не найдено).
Дата формирования отчёта (now) — дата запуска генерации отчёта (год, месяц, день).
TARGET_YEAR — год даты формирования отчёта.

================================================================================
1. ЧИСЛЕННОСТЬ СОТРУДНИКОВ (на дату отчёта)
================================================================================

Источник: лист «Список сотрудников».

Расчёт:
  Численность = количество строк, в которых заполнено поле «ФИО».

Исключаются:
  - строки с пустым ФИО;
  - строки, где ФИО совпадает со служебными словами (итого, всего, сумма и т.п.).

По смыслу: учитываются только сотрудники, которые на дату отчёта числятся в
текущем списке (активные, не уволенные).

================================================================================
2. СРЕДНИЙ СТАЖ (лет)
================================================================================

Источник: лист «Список сотрудников» (активные сотрудники).

Для каждого сотрудника:
  Стаж = (дата отчёта − дата трудоустройства) в днях / 365,25.

Средний стаж:
  Средний стаж = среднее арифметическое стажа по всем активным сотрудникам
  (у кого заполнены ФИО и дата трудоустройства).

В отчёте используется значение за последний месяц из помесячной серии (см. п. 11):
  для текущего месяца стаж считается на конец месяца (или на дату отчёта для
  текущего месяца).

================================================================================
3. СРЕДНИЙ ВОЗРАСТ (лет)
================================================================================

Источник: лист «Список сотрудников» (активные сотрудники).

Для каждого сотрудника:
  Возраст = (дата отчёта − дата рождения) в днях / 365,25.

Средний возраст:
  Средний возраст = среднее арифметическое возраста по всем активным сотрудникам
  (у кого заполнены ФИО и дата рождения).

В отчёте используется значение за последний месяц из помесячной серии (см. п. 11).

================================================================================
4. РАСПРЕДЕЛЕНИЕ ПО ПОЛУ (мужчины / женщины)
================================================================================

Источник: лист «Список сотрудников» (активные сотрудники).

Поле «Пол» нормализуется по первой букве:
  - «м» (м, мужской, муржчина и т.п.) → мужчина;
  - «ж» (ж, женский, женщина и т.п.) → женщина.

Расчёт:
  Количество мужчин = число активных сотрудников с полом «м»;
  Количество женщин = число активных сотрудников с полом «ж».

В отчёте используются фактические значения из «Список сотрудников» на дату отчёта
(не из помесячной серии).

================================================================================
5. ПРИНЯТО С НАЧАЛА ГОДА (с 01.01 по дату формирования отчёта)
================================================================================

Период: с 1 января TARGET_YEAR по дату формирования отчёта (включительно).

Источники (учитываются все листы):
  (1) Лист «Список сотрудников»
  (2) Лист «Увольнение»
  (3) Лист «Увольнения Склад и Торги» (если загружен)

Расчёт по листу «Список сотрудников»:
  Принято_из_списка = число записей, у которых:
    - дата трудоустройства заполнена;
    - дата трудоустройства >= 01.01.TARGET_YEAR;
    - дата трудоустройства <= дата формирования отчёта.

Расчёт по листам увольнений («Увольнение» + «Увольнения Склад и Торги»):
  Учитываются все записи, попавшие хотя бы в одну категорию:

  (а) Дата приёма в периоде:
      дата трудоустройства заполнена и попадает в [01.01.TARGET_YEAR; дата отчёта].

  (б) Без даты приёма, но дата увольнения в периоде:
      дата трудоустройства пустая, дата увольнения в [01.01.TARGET_YEAR; дата отчёта]
      (считаем принятыми в текущем году — приняты и уволены в том же году).

  (в) Приём в декабре прошлого года, увольнение в текущем:
      дата трудоустройства в [01.12.(TARGET_YEAR−1); 31.12.(TARGET_YEAR−1)],
      дата увольнения в [01.01.TARGET_YEAR; дата отчёта]
      (считаем принятыми за отчётный год).

  (г) Приём и увольнение в одном году (год приёма = TARGET_YEAR):
      дата увольнения в периоде, год даты трудоустройства = TARGET_YEAR,
      запись ещё не учтена в (а) или (в).

Итого:
  Принято с начала года = Принято_из_списка + сумма по листам увольнений (а)+(б)+(в)+(г).

Один человек не может одновременно быть в «Список сотрудников» и в реестре
увольнений, поэтому двойной учёт не возникает.

================================================================================
6. УВОЛЕНО С НАЧАЛА ГОДА (YTD)
================================================================================

Период: с 1 января TARGET_YEAR по дату формирования отчёта (включительно).

Источники: листы «Увольнение» и «Увольнения Склад и Торги» (объединённый реестр).

Расчёт:
  Уволено с начала года = число записей, у которых:
    - дата увольнения заполнена;
    - дата увольнения >= 01.01.TARGET_YEAR;
    - дата увольнения <= дата формирования отчёта.

Дубликаты по парам (ФИО, дата увольнения) при объединении листов удаляются.

================================================================================
7. ПРИНЯТО ЗА ТЕКУЩИЙ МЕСЯЦ
================================================================================

Период: с 1-го числа текущего месяца по дату формирования отчёта (включительно).

Источник: объединённый список (df_all) — «Список сотрудников» + листы увольнений,
с удалением дубликатов по (ФИО, дата трудоустройства).

Расчёт:
  Принято за месяц = число записей, у которых:
    - дата трудоустройства заполнена;
    - дата трудоустройства >= начало текущего месяца;
    - дата трудоустройства <= дата формирования отчёта.

Учитываются в том числе сотрудники, принятые и уже уволенные в этом же месяце.

================================================================================
8. УВОЛЕНО ЗА ТЕКУЩИЙ МЕСЯЦ
================================================================================

Период: с 1-го числа текущего месяца по дату формирования отчёта (включительно).

Источник: объединённый реестр увольнений («Увольнение» + «Увольнения Склад и Торги»).

Расчёт:
  Уволено за месяц = число записей, у которых:
    - дата увольнения заполнена;
    - дата увольнения >= начало текущего месяца;
    - дата увольнения <= дата формирования отчёта.

================================================================================
9. ТЕКУЧЕСТЬ ЗА ГОД (%)
================================================================================

Формула:
  Текучесть за год = (Уволено с начала года / Численность на дату отчёта) × 100.

Численность на дату отчёта — см. п. 1 (количество активных в «Список сотрудников»).

Если численность = 0, текучесть принимается равной 0.

================================================================================
10. ТЕКУЧЕСТЬ ЗА ПЕРИОД (текущий месяц, %)
================================================================================

Берётся из помесячной серии за последний месяц (текущий месяц), чтобы цифра
в отчёте совпадала с последней точкой на графике динамики текучести.

Формула для месяца (используется при расчёте серии):
  Текучесть за месяц = (Уволено за месяц / Численность на конец месяца) × 100.

Численность на конец месяца — см. п. 11 (активные на конец месяца по df_all).

================================================================================
11. ПОМЕСЯЧНЫЕ СЕРИИ (последние 7 месяцев)
================================================================================

Для каждого из 7 месяцев (от «минус 6 месяцев» до текущего месяца) считаются:

11.1. Численность на конец месяца (headcount_7)
  Источник: объединённый список df_all.
  Активный на конец месяца = дата трудоустройства заполнена и <= конец месяца,
  и (дата увольнения пустая или дата увольнения > конец месяца).
  Численность на конец месяца = количество таких записей.

  Для текущего месяца «конец месяца» = дата формирования отчёта; для прошлых
  месяцев — последний день соответствующего месяца.

11.2. Средний стаж на конец месяца (avg_tenure_7)
  По активным на конец месяца: стаж = (конец месяца − дата трудоустройства) в днях / 365,25.
  Средний стаж = среднее по этим значениям.

11.3. Средний возраст на конец месяца (avg_age_7)
  По активным на конец месяца: возраст = (конец месяца − дата рождения) в днях / 365,25.
  Средний возраст = среднее по этим значениям.

11.4. Распределение по полу на конец месяца (male_count_7, female_count_7)
  По активным на конец месяца считаются количество мужчин (пол «м») и женщин (пол «ж»).

11.5. Уволено за месяц (terminations_7)
  Число записей в реестре увольнений с датой увольнения в границах этого месяца.

11.6. Текучесть за месяц (turnover_series_7)
  Текучесть за месяц = (Уволено за месяц / Численность на конец месяца) × 100.

11.7. Текучесть по полу за месяц (male_turnover_7, female_turnover_7)
  Активные на начало месяца и на конец месяца разбиваются по полу.
  Среднесписочная численность по полу за месяц = (число на начало + число на конец) / 2.
  Текучесть по мужчинам = (уволено мужчин за месяц / среднеспис. мужчин) × 100.
  Текучесть по женщинам = (уволено женщин за месяц / среднеспис. женщин) × 100.

================================================================================
12. ПРИНЯТЫЕ / УВОЛЕННЫЕ ПО ОТДЕЛАМ (за текущий месяц)
================================================================================

Источники: df_all (принятые), объединённый реестр увольнений (уволенные).
Поле отдела: «ОтделФакт» (или «Отдел» на листе «Увольнения Склад и Торги»).

Принято по отделу за месяц:
  Число записей в df_all с данным отделом, у которых дата трудоустройства
  попадает в текущий месяц (от 1-го числа до даты отчёта).

Уволено по отделу за месяц:
  Число записей в реестре увольнений с данным отделом, у которых дата увольнения
  попадает в текущий месяц.

В отчёте выводятся топ-10 отделов по сумме (принято + уволено), для графика
«Принятые/уволенные по отделам» используются эти списки (принято — зелёные
столбцы вверх, уволено — красные вниз от нулевой линии).

================================================================================
13. СПИСКИ ПРИНЯТЫХ И УВОЛЕННЫХ ЗА МЕСЯЦ (для таблиц)
================================================================================

Список принятых за месяц:
  Из df_all выбираются записи с датой трудоустройства в текущем месяце;
  выводятся ФИО, отдел, дата приёма (в т.ч. уже уволенные в этом месяце).

Список уволенных за месяц:
  Из реестра увольнений выбираются записи с датой увольнения в текущем месяце;
  выводятся ФИО, отдел, дата увольнения.

================================================================================
14. РЕЖИМ DEMO
================================================================================

При DATA_MODE = "demo" часть метрик подменяется фиксированными значениями
(например, принято с начала года, уволено с начала года, принято/уволено за месяц,
текучесть за год и за период, данные по отделам и помесячные ряды текучести),
чтобы отчёт можно было просмотреть без реального Excel-файла.

================================================================================
15. ДАТЫ И ФОРМАТЫ
================================================================================

Даты из Excel по возможности парсятся в формате ДД.ММ.ГГГГ; при необходимости
используется общий парсинг pandas. Для листов увольнений при пустой дате
трудоустройства выполняется попытка подставить её из других столбцов или по
дате увольнения (в рамках правил п. 5).

Нормализация пола: по первой букве значения в поле «Пол» (м/ж).
