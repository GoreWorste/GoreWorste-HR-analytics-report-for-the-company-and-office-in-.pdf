ФОРМУЛЫ ДЛЯ HR-ОТЧЁТА ЗА НОЯБРЬ 2025
====================================

Обозначения (для простоты):
- "сотрудник активен" — дата найма есть, а дата увольнения не заполнена или позже проверяемой даты.
- now — дата отчёта, в нашем случае 30.11.2025.
- Год отчёта: 2025.

--------------------------------------------------
1. Количество сотрудников (чел)
--------------------------------------------------

Берётся из основной HR-таблицы (лист HR).

Формула по смыслу:
- Посчитать количество строк, где в столбце «ФИО» есть значение (строка не пустая).

То есть:
- Количество сотрудников = число всех записей о сотрудниках в таблице HR.

--------------------------------------------------
2. Кто считается активным сотрудником на дату отчёта
--------------------------------------------------

Сотрудник считается активным на дату now (30.11.2025), если:
- Дата найма НЕ пустая
И
- Дата увольнения ПУСТАЯ
  ИЛИ
  Дата увольнения БОЛЬШЕ now.

Проще:
- Активный сотрудник = (принят И ещё не уволен на текущую дату).

--------------------------------------------------
3. Возраст и стаж (в годах)
--------------------------------------------------

Для каждого сотрудника:

Возраст (в годах):
- Возраст = (дата отчёта — дата рождения) / 365,25
  (365,25 используется для учёта високосных лет).

Стаж (в годах):
- Стаж = (дата отчёта — дата трудоустройства) / 365,25

Средние значения считаются только по АКТИВНЫМ сотрудникам.

Средний возраст:
- Средний возраст = (сумма возрастов всех активных сотрудников) / (количество активных сотрудников)

Средний стаж:
- Средний стаж = (сумма стажа всех активных сотрудников) / (количество активных сотрудников)

--------------------------------------------------
4. Распределение сотрудников по полу (текущий срез)
--------------------------------------------------

Берутся сотрудники, которые:
- есть в основной HR-таблице
И
- у которых дата увольнения ПУСТАЯ (то есть они сейчас работают).

Дальше для них смотрим поле «Пол»:
- Мужчины: значение «м»
- Женщины: значение «ж»

Числа:
- Количество мужчин = число активных сотрудников с полем «м»
- Количество женщин = число активных сотрудников с полем «ж»

Проценты:
- Мужчины, % = Количество мужчин / (Количество мужчин + Количество женщин) * 100
- Женщины, % = Количество женщин / (Количество мужчин + Количество женщин) * 100

--------------------------------------------------
5. Границы года и месяца отчёта
--------------------------------------------------

Год отчёта: 2025.

Начало года:
- 01.01.2025

Текущий месяц для отчёта: НОЯБРЬ 2025.

Границы ноября:
- Начало месяца = 01.11.2025
- Конец месяца = 30.11.2025

--------------------------------------------------
6. Принято с начала года (по 30 ноября включительно)
--------------------------------------------------

Берутся записи из основной HR-таблицы.

Учитываются сотрудники, у которых:
- Дата найма заполнена
И
- Дата найма находится в диапазоне с 01.01.2025 по 30.11.2025 включительно.

Формула по смыслу:
- Принято с начала года = количество строк,
  где Дата найма >= 01.01.2025 и Дата найма <= 30.11.2025.

--------------------------------------------------
7. Уволено с начала года (по 30 ноября включительно)
--------------------------------------------------

Берутся записи из таблицы увольнений.

Учитываются сотрудники, у которых:
- Дата увольнения заполнена
И
- Дата увольнения находится в диапазоне с 01.01.2025 по 30.11.2025 включительно.

Формула по смыслу:
- Уволено с начала года = количество строк,
  где Дата увольнения >= 01.01.2025 и Дата увольнения <= 30.11.2025.

--------------------------------------------------
8. Принято за ноябрь
--------------------------------------------------

Берутся записи из основной HR-таблицы.

Учитываются сотрудники, у которых:
- Дата найма заполнена
И
- Дата найма находится в диапазоне с 01.11.2025 по 30.11.2025 включительно.

Формула по смыслу:
- Принято за ноябрь = количество строк,
  где Дата найма >= 01.11.2025 и Дата найма <= 30.11.2025.

--------------------------------------------------
9. Уволено за ноябрь
--------------------------------------------------

Берутся записи из таблицы увольнений.

Учитываются сотрудники, у которых:
- Дата увольнения заполнена
И
- Дата увольнения находится в диапазоне с 01.11.2025 по 30.11.2025 включительно.

--------------------------------------------------
10. Текучесть за год (годовая)
--------------------------------------------------

Используются две величины:
- Уволено с начала года (из п.7)
- Количество сотрудников (из п.1)

Формула:
- Текучесть за год, % =
    (Уволено с начала года) / (Количество сотрудников + Уволено с начала года) * 100

Если знаменатель (Количество сотрудников + Уволено с начала года) = 0,
то текучесть считается равной 0.

Смысл формулы:
- В числителе — сколько людей ушло за год.
- В знаменателе — условная «средняя база» (текущие + ушедшие).

--------------------------------------------------
11. Текучесть за период 30 дней
--------------------------------------------------

Период: последние 30 дней до даты отчёта.

1) Определяем дату начала периода:
- Дата начала периода = now − 30 дней.

2) Считаем, сколько сотрудников было активно на дату начала периода:
- Активен на дату начала периода =
    (Дата найма <= Дата начала периода)
    И
    (Дата увольнения ПУСТАЯ ИЛИ Дата увольнения > Дата начала периода)

3) Считаем, сколько сотрудников уволилось в течение этих 30 дней:
- Уволен в период 30 дней =
    Дата увольнения >= Дата начала периода.

4) Формула текучести за период:
- Текучесть за период, % =
    (Число уволенных за последние 30 дней)
    / (Число активных на дату начала периода)
    * 100

Если число активных на дату начала периода = 0,
то текучесть за период считается равной 0.

--------------------------------------------------
12. Помесячные ряды за последние 7 месяцев
--------------------------------------------------

Период: последние 7 месяцев до ноября включительно.
Если текущий месяц — ноябрь, то месяцы:
май, июнь, июль, август, сентябрь, октябрь, ноябрь.

Для каждого месяца m из этих 7:

1) Границы месяца:
- Начало месяца m_start = первое число месяца m.
- Конец месяца m_end = последнее число месяца m.

2) Численность на конец месяца:
- Сотрудник считается активным на конец месяца, если:
    Дата найма <= m_end
    И
    (Дата увольнения ПУСТАЯ ИЛИ Дата увольнения > m_end)
- Численность на конец месяца =
    количество таких активных сотрудников.

3) Средний стаж на конец месяца:
- Для каждого активного на конец месяца сотрудника считаем:
    Стаж_на_конец = (m_end − Дата найма) / 365,25
- Средний стаж по месяцу =
    (сумма стажа всех активных на конец месяца)
    / (количество этих сотрудников).

4) Средний возраст на конец месяца:
- Для каждого активного на конец месяца сотрудника считаем:
    Возраст_на_конец = (m_end − Дата рождения) / 365,25
- Средний возраст по месяцу =
    (сумма возрастов всех активных на конец месяца)
    / (количество этих сотрудников).

5) Разбивка по полу на конец месяца:
- Количество мужчин в месяце m =
    количество активных на конец месяца сотрудников с полем «м».
- Количество женщин в месяце m =
    количество активных на конец месяца сотрудников с полем «ж».

6) Проценты по полу на конец месяца:
- Мужчины, % =
    Количество мужчин / (Количество мужчин + Количество женщин) * 100
- Женщины, % =
    Количество женщин / (Количество мужчин + Количество женщин) * 100

--------------------------------------------------
13. Текучесть по каждому из последних 7 месяцев
--------------------------------------------------

Для каждого месяца m (май–ноябрь):

1) Сколько было активных в начале месяца:
- Активен на начало месяца =
    Дата найма <= начало месяца
    И
    (Дата увольнения ПУСТАЯ ИЛИ Дата увольнения > начало месяца)
- Active_Start(m) = количество таких сотрудников.

2) Сколько было активных в конце месяца:
- Активен на конец месяца =
    Дата найма <= конец месяца
    И
    (Дата увольнения ПУСТАЯ ИЛИ Дата увольнения > конец месяца)
- Active_End(m) = количество таких сотрудников.

3) Сколько уволилось в течение месяца m:
- Уволен в месяце m =
    Дата увольнения находится между началом и концом месяца включительно.
- Termed(m) = количество таких сотрудников.

4) Средняя численность за месяц:
- Средняя численность(m) =
    (Active_Start(m) + Active_End(m)) / 2

5) Текучесть за месяц m:
- Если Средняя численность(m) > 0, то:
    Текучесть(m), % =
        Termed(m) / Средняя численность(m) * 100
- Если Средняя численность(m) = 0, то:
    Текучесть(m) = 0.

--------------------------------------------------
14. График «Динамика сотрудников по полу» (столбики)
--------------------------------------------------

На графике по оси X — последние 7 месяцев.
По оси Y — количество сотрудников.

Для каждого месяца m:
- Синий столбик = Количество мужчин на конец месяца m.
- Красный столбик = Количество женщин на конец месяца m.

Над каждым столбиком подписано его значение в людях (чел).

Таким образом, график показывает, как меняется во времени
численность мужчин и женщин в компании помесячно.
