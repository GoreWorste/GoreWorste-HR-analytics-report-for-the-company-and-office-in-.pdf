# Changelog

## [ИСПРАВЛЕНИЕ] Добавлен учет увольнений склада - 30.12.2025

### Проблема
В отчете не учитывались увольнения склада, которые ведутся на отдельном листе "Увольнения Склад и Торги" в Реестре сотрудников. Это приводило к существенным расхождениям в метриках:
- Неверное количество увольнений с начала года
- Неверное количество увольнений за текущий период
- Неверный расчет текучести персонала

### Решение
Модифицирован файл `main.py` для загрузки и обработки увольнений из обоих листов:
1. **Лист "Увольнение"** (header=2) - основные увольнения
2. **Лист "Увольнения Склад и Торги"** (header=0) - увольнения склада

### Изменения в коде

#### 1. Добавлена загрузка второго листа с увольнениями (строки 232-264)
```python
# Лист "Увольнения Склад и Торги" (дополнительные увольнения, заголовки в строке 0)
logger.info("Загрузка листа 'Увольнения Склад и Торги'...")
df_term_warehouse_raw = None
try:
    df_term_warehouse_raw = pd.read_excel(data_source, sheet_name="Увольнения Склад и Торги", header=0)
    # ... обработка данных
except Exception as e:
    logger.warning("ВНИМАНИЕ: Лист с увольнениями склада не найден!")
```

#### 2. Добавлена обработка и объединение данных (строки 365-443)
```python
# Обработка данных из листа "Увольнения Склад и Торги"
if df_term_warehouse_raw is not None:
    df_term_warehouse = df_term_warehouse_raw.copy()
    # ... фильтрация, нормализация данных
    
    # Объединяем два датафрейма с увольнениями
    df_term_combined = pd.concat([df_term, df_term_warehouse], ignore_index=True)
    
    # Убираем дубликаты
    df_term_combined = df_term_combined.drop_duplicates(subset=["ФИО", "termination_date"], keep="first")
    
    df_term = df_term_combined
```
